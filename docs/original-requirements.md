# Family Scheduler: Original Requirements

I would like to build a task scheduling/todo list web application with built in reminders at my family can use to keep track of our schedules. The type of things we need to track are Alex's school events, school assignments, orchestra events, practice schedule, concert dates, work events, family events, etc. The items should have a space for a name, date of the event or due date, address/location, comments/feedback, reminder notifications via push notification and email and if there is a way to do text message reminders for free, I would like to include that as well. The web app should allow users to sign in with their email address and a password assigned to them. Only pre-configured email addresses should have access to the app and users should be able to create private lists/events as well as shared ones that the family can view and edit.

The reason I am building such an app is because it's been difficult to keep track of our schedule and remember when things are due or when an event is scheduled. Having a common place for us to create and view our schedule will help us be on the same page. Currently one of us is sending text messages, emails and verbally communicating this type of information to the rest of the family and it's hard to keep track of it and remember it all along with all the other things we have going on on a daily basis.

Ask me any additional questions. I would like to host this web app for free and since I have a Cloudflare account I can host it there or in my AWS account. If those options are not free, I am even willing to use Google drive to host the data and files and host the web app itself in AWS or Cloudflare (or some other service). I do not need a custom domain for this app, it will be the system generated url.

I will be creating a github repo and using my AI Agents to build and test this web app.
